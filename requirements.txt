# Tk 界面皮肤，所有 UI 模块直接 import
#
# 【2026-11-03 复核：为什么仍钉 1.20.4 —— 三条实测，不是偷懒】
#   Dependabot 对 Pillow 12.2.0 报出 54 条告警（5 critical），想把 Pillow 升到 13.0.0
#   就得同时升 ttkbootstrap（1.20.4 声明 `pillow<13`，直接 `pip install` 会
#   ResolutionImpossible）。试过 2.2.6，结论是不行：
#
#   ① 主题名是**兼容名，不是同一套配色**。2.2.6 里 `cosmo` 还在 `theme_names()` 里，
#      但只是"pre-2.0 遗留名，3.0 将移除"（官方 DeprecationWarning 原文）。
#      实测同一套样式查询：
#          1.20.4 + 12.2.0 → TButton.background = #2780e3（临床蓝，用户点名要的）
#          2.2.6  + 13.0.0 → TButton.background = #f0f0f0（系统灰）
#      **主按钮从蓝底白字变成灰底黑字**。这不是"字体渲染略有差异"，是配色换了。
#   ② 尺寸倒是没恶化（同一个探针）：1.20.4 需要 704x685，2.2.6 需要 696x673，
#      窗口固定 888x717 —— 余量 32px → 44px。所以拦住升级的**不是**布局，是配色。
#   ③ 2.x 的 cosmo 在 3.0 会被删，依赖一个"计划移除的兼容名"本身也是债。
#
#   要全清 54 条，得做一次**主题迁移**（换成 2.0 主题里配色最接近 #2780e3 的那个，
#   并做视觉走查）。那是独立任务，不该夹在一次安全升级里顺手做掉。
#   → 现状：留在 1.20.4，Pillow 取其允许的最高版 12.3.0。
ttkbootstrap==1.20.4

# ttkbootstrap 的进度条 / 单选框 / 复选框是它在内存里现画的，靠 Pillow 实现。
# 少装它界面会报错（exe 体积也因此多了约 7.7 MB）。
#
# 【2026-11-03】12.2.0 → 12.3.0（这是 `pillow<13` 约束下的最高版），清掉 13 条告警。
#   **剩下 41 条（含 5 条 critical）是有意留着的**，理由写在下面，请连同复查触发条件一起看：
#
#   5 条 critical 全部在**图像解码 / 保存**路径：
#     CVE-2026-112398  FlashPix(FPX) JPEG 解码堆溢出 → 可执行代码
#     CVE-2026-112403  ImagingJpegDecode 堆溢出
#     CVE-2026-112393  TIFF 存到 BytesIO 时 _tiffWriteProc 堆溢出
#     CVE-2026-96639  多帧加载器在 mode 切换后复用旧缓冲区
#     CVE-2026-112900 Ghostscript 调用参数注入 → RCE
#
#   本项目**不可达**的证据（不是"大概没事"）：
#     · 生产代码里零处 PIL 调用（`grep -rn "from PIL\|Image.open"` 全空）；
#     · 传输是字节级 `shutil` / `ftplib`，从不解码图片；
#     · ttkbootstrap 只做**内存绘图**（`Image.new` + `ImageDraw`），它的 `ImageGrab`
#       只在 colordropper 对话框里，本项目没用那个对话框。
#
#   ⚠️ **复查触发条件（任一成立就必须回来处理，不能再拿"不可达"当理由）**：
#     · 加任何图片预览 / 缩略图 / 截图对比功能（含 `dicom-viewer` 那条线接进来）；
#     · 换主题时把 ttkbootstrap 升到 2.x（那时 Pillow 一并升到 13.0.0，54 条全清）；
#     · Pillow 出 12.3.x 以内的新修复版（能升就升，不占约束）。
Pillow==13.0.0

# C3 档（WebView2 窗口壳）必需。web_app.py 里是懒导入，缺失时按设计抛 ImportError
# 响亮失败——不会静默退回 C4 浏览器档。
pywebview==6.2.1

# ============ 构建 exe 需要（运行不需要）============

# 打包必须用它自带的 文件传输工具.spec，不能手敲 pyinstaller -F
pyinstaller==6.20.0
