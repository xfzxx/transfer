# Tk 界面皮肤，所有 UI 模块直接 import
#
# 【2026-11-03 主题迁移：1.20.4 → 2.2.6，cosmo → bootstrap-light】
#   起因是依赖链被锁死，不是想换皮：
#       Pillow 13.0.0（清掉全部 54 条 Dependabot 告警）
#         ↑ 要求 ttkbootstrap >= 2.x（1.20.4 声明 pillow<13，pip 直接 ResolutionImpossible）
#         ↑ 而 2.x 里 `cosmo` 只是"pre-2.0 遗留兼容名"（官方标注 3.0 将移除），
#           且实测配色根本不是原来那套：TButton.background 由 #2780e3 变 #f0f0f0。
#   ⇒ 换了 2.x 的真主题 bootstrap-light（主色 #0a58ca，白底），选它的理由与色差表
#     写在 `config.C_UI_THEME` 的注释里，那边是唯一真相，这里不重复。
#
#   迁移前实测过（不是"感觉应该没事"）：
#     ① 7 种在用 bootstyle（primary / secondary / secondary-outline / warning /
#        danger / primary-outline / danger-round-toggle）在 2.2.6 下全部可建；
#     ② 真窗口截图：主按钮仍是蓝底白字，白底扁平观感与 cosmo 一致，无错位/裁切；
#     ③ 布局由 `tests/test_layout_budget.py` 判，2.2.6 需要 696x673，窗口 888x717
#        （1.20.4 时是 704x685）—— **余量反而变大**，日志区没被挤。
#
#   ⚠️ 唯一遗留 warnings：Checkbutton 用 `-outline` 组合时会打
#      "invalid bootstyle combination"，是 2.x 的固有行为（outline 只对 button 有意义），
#      现有代码里 outline 只用在 Button 上，不影响。
ttkbootstrap==2.2.6

# ttkbootstrap 的进度条 / 单选框 / 复选框是它在内存里现画的，靠 Pillow 实现。
# 少装它界面会报错（exe 体积也因此多了约 7.7 MB）。
#
# 【2026-11-03】12.2.0 → 13.0.0：**一次清掉全部 54 条告警**
#   （41 条修复线在 13.0.0，13 条在 12.3.0；severity 5 critical / 33 high / 16 medium，
#    全部落在 Pillow，pywebview 与 pythonnet **零告警**）。
#
#   5 条 critical 的具体内容（都值得记一笔，它们决定了"能不能不升"）：
#     CVE-2026-112398  FlashPix(FPX) JPEG 解码堆溢出 → 可执行代码
#     CVE-2026-112403  ImagingJpegDecode 堆溢出
#     CVE-2026-112393  TIFF 存到 BytesIO 时 _tiffWriteProc 堆溢出
#     CVE-2026-96639  多帧加载器在 mode 切换后复用旧缓冲区
#     CVE-2026-112900 Ghostscript 调用参数注入 → RCE
#
#   当初在 1.20.4 上这批**不可达**（生产代码零处 PIL 调用、从不解码图片，
#   ttkbootstrap 只做内存绘图），所以曾记档为"接受"。现在既然为了升 Pillow
#   换了主题，就不该再留着 —— 一次升级把两件事一起解决。
Pillow==13.0.0

# C3 档（WebView2 窗口壳）必需。web_app.py 里是懒导入，缺失时按设计抛 ImportError
# 响亮失败——不会静默退回 C4 浏览器档。
pywebview==6.2.1

# ============ 构建 exe 需要（运行不需要）============

# 打包必须用它自带的 文件传输工具.spec，不能手敲 pyinstaller -F
pyinstaller==6.20.0
