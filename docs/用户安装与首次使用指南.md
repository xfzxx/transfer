# 文件传输工具 · 用户安装与首次使用指南

> 这份是写给**不写代码的人**看的。不需要懂技术，照着一步步点就行。
> 全程大约 10 分钟，其中安装占 3~5 分钟（大部分时间在装 Windows 的一个组件）。

---

## 一、这是干什么用的

把一堆文件（病历、影像、导出数据）从一个文件夹搬到另一个文件夹，或者传到 FTP 服务器上。

它的好处是：

- **断了能接着传**：网络断了、机器重启了，下次从断的地方继续，不用从头再来
- **失败能重来**：哪几个没传成功会记下来，点一下「重传失败」只补这几个
- **可以定时**：设成半夜 2 点自动跑，早上来看结果
- **可以加密**：FTP 支持 FTPS，账号密码和文件内容都不在网络上裸奔

---

## 二、装之前，先备好两样东西

1. **管理员权限**
   装软件要用管理员身份。如果双击后弹出「你要允许此应用对你的设备进行更改吗？」，
   点 **「是」**。如果连这个框都没弹、直接提示没有权限，说明你这台机器需要找信息科装。

2. **FTP 的地址、账号、密码**
   如果只是本机两个文件夹之间搬文件，**这份东西不需要**，跳过即可。

---

## 三、安装（3 步）

1. 找到安装包，**双击**它：

   ```
   文件传输工具-2.6.1-安装包.exe     ← 完整版，231 MB
   文件传输工具-2.6.1-轻量版.exe     ← 轻量版，24 MB
   ```

   **该装哪个？**

   | 情况 | 装哪个 |
   |---|---|
   | 这台机器第一次装，不确定 | **完整版** |
   | 科室里已经有一台装了完整版 | 轻量版即可（省 200MB 传输时间） |
   | 内网不能上外网 | **完整版**（轻量版需要机器上已有 Windows 的 WebView2 组件） |

2. 一路点 **「下一步」/「我接受」**，安装位置保持默认就行：

   ```
   C:\Program Files\文件传输工具
   ```

   安装过程里如果屏幕上闪过「正在安装 WebView2 运行时」，那是正常现象，
   它在装一个 Windows 组件（约 1~2 分钟），等它自己跑完。

3. 装完勾选 **「立即运行 文件传输工具」** → 点完成。

> 桌面上会出现一个蓝色双向箭头的图标，以后就从这里打开。

---

## 四、第一次打开会看到什么

窗口里有一个蓝色按钮「开始传输」、一个源文件列表、一个目标路径框、下面一大片日志区。
如果你看到的界面是**开在浏览器里**（地址栏写着 `127.0.0.1:8765`），也完全正常：

- 开在**独立窗口**里 = 机器上有 WebView2 组件
- 开在**浏览器**里 = 没有那个组件，功能一模一样，只是外壳不同

想让它开在独立窗口里：让信息科装一次 WebView2 运行时即可（或重装完整版安装包）。

---

## 五、第一次配置 FTP（只在要传服务器时才需要）

1. 在「目标路径」右边，点那个 **⚙ 小齿轮**
2. 弹出「FTP 设置」窗口，填四项：

   | 填什么 | 举例 | 从哪来 |
   |---|---|---|
   | 主机 | `192.168.1.20` | 信息科给 |
   | 端口 | `21` | 默认 21；服务器要 990 就是「隐式 TLS」 |
   | 用户名 | `transfer` | 信息科给 |
   | 密码 | `******` | 信息科给 |
   | 远程目录 | `/upload` | 服务器上放文件的目录 |

3. **加密模式**（很重要，默认是「无」）：

   | 选项 | 什么时候选 |
   |---|---|
   | 无（明文） | 只在完全隔离的内网、且信息科明确说不用加密时 |
   | **显式 TLS（AUTH TLS）** | **医院里优先选这个**（绝大多数服务器支持，端口还是 21） |
   | 隐式 TLS（FTPS） | 服务器明确要求 990 端口时 |

4. 如果服务器用的是**自建/自签证书**，勾上 **「允许自签名证书」**。
   不勾的话连不上，会报证书错误——那是正常的，说明校验在工作。

5. 点 **「测试连接」**：

   - 提示成功 → 点「保存」
   - 提示失败 → 先看下面的「连不上怎么办」

### 连不上怎么办

| 提示 | 多半是 |
|---|---|
| 连接超时 / 无法连接 | 地址或端口错；或者这台机器到服务器不通（找信息科开防火墙） |
| 用户名或密码错误 | 账号错，注意大小写 |
| 证书错误 / SSL 相关 | 勾上「允许自签名证书」再试；还不行就把加密模式换「显式 TLS」 |
| 530 权限不足 | 账号没权限进那个远程目录 |

## 六、传一次文件（最短流程）

1. 点 **「＋」** → 「选择文件夹」，挑要传的那个目录（可以加多个，
   按住 Ctrl 点能一次选好几个，「－」一次删掉所有选中的）
2. 目标路径：点「浏览…」选本地目录，或者按第五节配好 FTP 后选服务器那套
3. 点 **「开始传输」**
4. 看进度条和日志。想停就点「暂停」或「停止」

**开始前它会自己检查一遍**：目标写不写得进去、源目录是不是空的、空间够不够。
有问题会当场弹框拦住，不会让你传到一半才失败。

---

## 七、想设成半夜自动跑

1. 切到「定时任务」页 → 新建一条
2. 选源、选目标、选时间（每天 / 每周 / 每几小时 / 只跑一次）
3. 保存后系统里就有了计划任务，到点自动跑，**不会弹窗口**

第二天早上打开程序，界面顶部会显示一行：

```
上次定时任务：2026-11-06 02:00:00 成功 · 复制 500 个
```

没这行字 = 还没跑过，或者时间还没到。

## 八、核对 SHA256（防"传坏了"和"杀软误报"）

为什么要做：安装包 200 多 MB，经过微信/网盘/U 盘转手有可能损坏；
另外程序没有买代码签名证书，有些杀毒软件会紧张。核对一下能确认**这个文件就是原版**。

**做法（1 分钟）**：

1. 按 `Win + R`，输入 `cmd`，回车（会开一个黑窗口）
2. 把安装包所在文件夹的路径复制出来，在黑窗口里输入 `cd ` 然后粘贴路径，回车
   （例如 `cd /d D:\交付\文件传输工具`）
3. 输入下面这行，回车（把文件名换成你那个）：

   ```
   certutil -hashfile 文件传输工具-2.6.1-安装包.exe SHA256
   ```

4. 屏幕上会出现一串 64 位的字母数字，把它和 `SHA256SUMS.txt` 里那一行**逐字比对**：

   ```
   614cfe938854c9562bbb585b7d0d73aa85a67d532008bbb251023e5a8fc2d8a1  文件传输工具-2.6.1-安装包.exe
   ```

   - **一样** → 文件完好，放心装
   - **不一样** → 别装，重新拷一份。两次都不一样就找发你文件的人

> 轻量版同理，用 `SHA256SUMS.txt` 里对应的那一行。

### 杀毒软件报毒怎么办

程序没做代码签名（要买证书，走医院采购流程），所以：

- Windows 提示「未知发布者」→ 点「更多信息」→「仍要运行」
- 杀软直接拦 → 把**安装包**和 `C:\Program Files\文件传输工具` 加进白名单
- 要报给厂商申诉 → 附上第八节算出来的 SHA256，他们能确认是同一个文件

## 九、以后升级

不用先卸载。直接把新版本安装包装一遍：

- 会装在**原来的目录**，不会装出两份
- 你配的 FTP、定时任务、最近用过的路径**都会保留**
- 装的是比现在旧的版本时，它会问你一句（怕你装错包）

---

## 十、卸载

「设置 → 应用」里搜「文件传输工具」→ 卸载。或者运行安装目录里的 `uninstall.exe`。

卸载时会问你一句：**要不要连配置和传输记录一起删？**

- 选「否」→ 配置留着，以后重装还能接着用
- 选「是」→ 连 `data` 目录一起清干净

WebView2 组件不会被一起删掉（别的软件也可能在用），它在「设置 → 应用」里单独卸。

---

## 十一、东西都存在哪、出问题看哪

```
C:\Program Files\文件传输工具\
├── 文件传输工具.exe
├── 部署说明.txt          ← 给信息科看的技术版
└── data\                 ← 配置、记录都在这
    ├── last_run.json          上次定时任务的结果
    ├── .ftp_transfer_state.db 传输记录（失败清单从这读）
    └── logs\                  定时任务的运行日志
```

**出问题时，把 `data\logs\` 里的日志发给信息科**，基本能定位。
传输很慢、日志里反复出现「从头开始」→ 多半是服务器不支持断点续传，
这属于服务器能力限制，日志里那几行探测结果能直接说明。
